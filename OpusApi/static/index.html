How it works

One link in, one stream out

Every request follows the same path — resolve the link, check the cache, stream the file.

01

Send a link

Your bot calls /download with a YouTube URL or video ID.

02

Get a stream token

The API resolves the video and returns a short-lived token bound to it.

03

Cache is checked

If the track's been requested before, it's served instantly — no re-download.

04

Audio streams back

Your bot receives the file directly, ready to forward to the user.

Everything the API can do

GET /download

Resolves a YouTube link and returns a short-lived stream token bound to that video.

GET /download?url=dQw4w9WgXcQ&type=audio
ParamTypeDescription
urlstringA YouTube URL, share link, or bare 11-character video ID.
typestringaudio or video. Defaults to audio.
{ "status": "success", "video_id": "dQw4w9WgXcQ", "download_token": "OpusApi...OpusBots", "stream_url": "https://.../stream/dQw4w9WgXcQ?..." }

GET /stream/{video_id}

Streams the actual audio or video file. Requires a valid token — either the one just issued by /download, or your own API token.

GET /stream/dQw4w9WgXcQ?type=audio&token=YOUR_TOKEN

Authentication

Pass your token as the token query parameter, or as an X-Download-Token header. Generate a token below — it's free, and takes under a minute.

curl "https://opusmusicapi.example.com/stream/VIDEO_ID?type=audio" \ -H "X-Download-Token: YOUR_TOKEN"

Rate limits

Free tokens are valid for 28 days from creation and allow 200 requests. Once either limit is reached, generate a new token.

PlanRequestsValidity
Free token200 requests28 days

Errors

Errors return a standard HTTP status with a JSON body describing what went wrong.

{ "detail": "Token expired" } // 401 — token missing, invalid, revoked, or expired // 403 — blocked by admin, or channels not joined // 404 — token not found // 500 — the video couldn't be fetched
