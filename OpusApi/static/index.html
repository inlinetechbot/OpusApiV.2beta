HOW IT WORKS

One link in, one stream out

Every request follows the same three-step path, whether the track's been requested before or not.

Resolve the link

Your bot calls /download with a YouTube URL or bare video ID. The API returns a stream token bound to that video.

Check the cache

If the track's been requested before, it's already sitting in permanent storage — no re-download, no wait.

Stream it back

Your bot receives the file directly from /stream/{video_id}, ready to forward to the user.

DOCUMENTATION

Everything the API can do

Three endpoints. Plain HTTP requests from any language your bot is written in.

Download Stream Authentication Rate limits Errors
GET/download

Resolves a YouTube link and returns a short-lived stream token bound to that video.

GET /download?url=dQw4w9WgXcQ&type=audio
ParamTypeDescription
urlstringA YouTube URL, share link, or bare 11-character video ID.
typestringaudio or video. Defaults to audio.
{ "status": "success", "video_id": "dQw4w9WgXcQ", "download_token": "OpusApi...OpusBots", "stream_url": "https://.../stream/dQw4w9WgXcQ?..." }
GET/stream/{video_id}

Streams the actual audio or video file. Requires a valid token — either the one just issued by /download, or your own API token.

GET /stream/dQw4w9WgXcQ?type=audio&token=YOUR_TOKEN

Authentication

Pass your token as the token query parameter, or as an X-Download-Token header. Generate one below — it's free, and takes under a minute.

# curl example curl "https://opusmusicapi.example.com/stream/VIDEO_ID?type=audio" \ -H "X-Download-Token: YOUR_TOKEN"

Rate limits

Free tokens are valid for 28 days from creation and allow 200 requests. Once either limit is reached, generate a new token.
